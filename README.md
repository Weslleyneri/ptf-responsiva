# Portfólio futurista — Weslley Neri

Versão estática e responsiva do portfólio pessoal de Weslley Neri, preparada para publicação gratuita no GitHub Pages.

## Recursos incluídos

- Tema escuro futurista com cores neon.
- Nome com animação flutuante e profundidade 3D.
- Foto com scanner holográfico e elementos orbitais.
- Seis projetos apresentados como cases interativos.
- Janelas com desafio, solução e tecnologias de cada projeto.
- Seções sobre liderança, stack e método de trabalho.
- Efeitos de movimento pelo mouse e pela rolagem.
- Adaptação para computador, tablet e celular.
- Publicação automática pelo GitHub Actions.

## Como publicar

1. Crie um repositório público no GitHub. Sugestão de nome: `portfolio-futurista`.
2. Extraia o arquivo ZIP deste projeto.
3. Envie todos os arquivos extraídos para a raiz do repositório, incluindo a pasta `.github`.
4. No repositório, acesse **Settings → Pages**.
5. Em **Build and deployment → Source**, selecione **GitHub Actions**.
6. Acesse a aba **Actions** e aguarde o fluxo “Publicar portfólio no GitHub Pages” finalizar.

O endereço padrão será:

`https://weslleyneri.github.io/portfolio-futurista/`

## Atualizações futuras

Edite os arquivos `index.html`, `globals.css`, `github-pages.css` ou `script.js` e envie as alterações para a branch `main`. A nova versão será publicada automaticamente.
